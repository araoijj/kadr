# Кадр — что доработать

Недоработки, найденные при сравнении с открытым кодом LightCraft (ArtCraft, MIT/Apache, Rust):
https://github.com/storytold/lightcraft. Код на Rust не переносим — берём идеи и подходы.

## 1. Профиль «Как в камере» (`CameraMatch.swift`)

Сейчас: 3D-LUT 17³ от проявки macOS к встроенному JPEG, считается в 8-битном sRGB, по кадру без рамки 1/12, применяется всегда.
Подход LightCraft описан в `docs/camera-preview-colour.md` их репозитория.

Быстрые доработки (на вечер):

- [ ] **Проверка подгонки.** Учить LUT на 2/3 пикселей, на оставшейся трети проверять. Если ошибка к JPEG не падает хотя бы на 30% по сравнению с обычной проявкой — профиль не применять (или применять ослабленным). Сейчас неудачная подгонка (JPEG не совпал с RAW по геометрии, другой кадр) молча даёт кривые цвета.
- [ ] **Не учиться на выбитых пикселях.** Исключать пиксели, где в RAW-проявке или в JPEG канал у предела (≥ 0.99). Белое небо с клипнутым каналом уводит светлые цвета в серость/пурпур.
- [ ] **Редкие цвета — к «без изменений», а не к соседям.** Где в ячейке LUT мало данных, стягивать сдвиг к нулю (с весом по насыщенности), а не растягивать сдвиг соседних ячеек. Иначе насыщенные цвета, которых в кадре почти нет, искажаются.

Средние:

- [ ] **Края по контрасту, а не рамкой.** Выкидывать пиксели, где в окрестности 3×3 перепад яркости больше 3×, по всему кадру — вместо фиксированной рамки 1/12. Сначала пробовать на всех пикселях, при провале проверки — без краёв.
- [ ] **Учесть коррекцию объектива в JPEG.** Sony с «Distortion Comp: Auto» отдаёт JPEG с исправленной дисторсией, RAW — без. Перед подгонкой выравнивать проявку RAW так же (или выбирать вариант, который лучше совпадает с JPEG по корреляции).

Большая переделка:

- [ ] **Разделить цвет и тон.** Сейчас LUT стоит после экспозиции в sRGB 0…1 и, вероятно, жёстко режет всё, что ярче 1.0 (подтянул экспозицию — света клипнулись на кубе). Вместо этого: цвет (матрица 3×3 + таблица оттенков/насыщенности) — в линейном пространстве, тональная кривая с мягким плечом — в конце конвейера. Тон подгонять сопоставлением квантилей яркости (RAW vs JPEG), с отдельной выборкой для глубоких теней.
- [ ] **Чёрно-белый JPEG.** Если камера снимала в монохромном стиле — брать из JPEG только тональную кривую, цвет не трогать.

## 2. Умная сортировка (`Cull.swift`, `Library.swift` → `groupSeries`)

Отзыв друга: анализ хороший, но проще сортировать руками. Сам анализ у Кадра сильнее, чем у LightCraft; не хватает ручного контроля.

- [ ] **Настройки серии.** Сейчас зашито: ≤ 30 с между кадрами и Хэмминг ≤ 12 / feature print < 0.45. Вынести в диалог отбора: интервал (по умолчанию 10–30 с, до суток) и порог похожести.
- [ ] **«Сделать лучшим в серии»** — ручной выбор лучшего кадра.
- [ ] **«Вынести из серии», «Новая серия», «Объединить серии»** — правка группировки руками (у LightCraft — окно Bursts с перетаскиванием).
- [ ] **Ручные правки не затираются.** Хранить флаг «расставлено вручную» в индексе; `groupSeries()` при повторном анализе такие кадры не перегруппировывает. Полная перегруппировка — только явной кнопкой.
- [ ] **«Отклонить всё ниже N баллов»** как отдельное массовое действие.
